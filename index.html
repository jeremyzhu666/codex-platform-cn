安装逻辑

1

先装 macFUSE（8.1+）

运行 macfuse-5.3.3.dmg 里的 Install macFUSE，装完在隐私与安全性中允许系统扩展，然后重启。

2

再装 CODEX Platform

打开下载的 .pkg，跟随向导完成安装，默认会选中所有未安装的组件。安装结束后如未提示重启，请手动重启一次。

3

授予完全磁盘访问

系统设置 → 隐私与安全性 → 完全磁盘访问，打开 Codex Platform。（7.6.2 及更早版本请找 drserver）

4

启动

应用程序 → Codex 文件夹 → 双击 Codex Platform，菜单栏出现齿轮图标即表示运行成功，之后每次登录自动启动。

⚠️ 使用 macOS 26 Tahoe 的话：26.1 / 26.2 的完全磁盘访问列表存在显示问题，请升级到 26.3 及以上。

核心功能：ARRI 无损压缩技术（HDE）

为 ARRIRAW 素材开启 High Density Encoding，在视觉无损的前提下大幅缩小文件体积—— offload 更快、占盘更少、网速更省。

  • 8.0 起，所有 ALEXA 机型均支持直接输出 MXF/HDE
  • Capture Drive 可同时挂载 MXF/HDE 与 MXF/ARRIRAW 两种视图，直接兼容 Silverstack 等 DIT 工具链
  • 7.5.1 起，ALEXA Mini / AMIRA 通过任意 CFast 2.0 读卡器即可输出 MXF/HDE，无需许可证
  • 所有 CODEX 读卡器配合 CODEX Platform，均可为 ARRIRAW 素材开启 HDE
